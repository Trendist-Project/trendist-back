# Trendist 1부. 기획

> 문서 목록과 변경 이력은 [docs/README.md](README.md). 절 번호(1~17)는 네 문서에 걸쳐 이어지고, 코드 주석의 `(4.8)` 같은 번호가 이 번호다.

## 1. 개요

| 항목 | 내용 |
|---|---|
| 서비스 | Trendist, 도메인 trendist.kr(예정) |
| 장르 | 실시간 멀티플레이 .io 아레나. 원형 아이콘끼리 부딪히면 큰 쪽이 작은 쪽을 밀어낸다 |
| 플랫폼 | 브라우저(데스크톱 우선, 모바일 대응), 설치 없음 |
| 운영 형태 | 라운드 없이 24시간 계속 유지되는 아레나 |
| 지역 | 나라별로 방·트렌드를 나눈다. 지금은 한국(KR)만 연다. 이후 글로벌(영어권 통합) → 일본·인도. 중국은 열지 않는다 |
| 언어 | 한국어 → 영어 → 일본어·중국어(간체)·힌디어 |
| 핵심 재미 | 뜨는 키워드를 찾아 `+`하면 커지고, 커지면 부딪힐 때 이긴다 |
| 데이터 | 한국은 네이버, 해외는 BigQuery Google Trends 공개 데이터셋. 외부 데이터는 "지금 뜨는 키워드인가"를 확인하는 데 쓰고, 점수의 크기는 가진 사람 수와 소스별 반영값으로 정한다 |

기획 배경
- 유행 주기가 급격히 짧아졌다. 탕후루 54일(2023), 두바이 초콜릿 13일(2024), 두쫀쿠 17일(2025 말)로 5년 사이 약 10분의 1이다(위키트리, 2026-07-25).
- 짧은 유행일수록 "누가 먼저 알았나"가 가치가 된다. 이 게임은 유행을 찾아 `+`한 만큼을 아이콘 크기로 보여 준다.
- 매일 바뀌는 키워드 데이터가 콘텐츠라서 특정 유행이 끝나도 게임이 낡지 않는다.

핵심 규칙 요약 (자세한 내용은 괄호의 절)
- 내 트렌드 키워드: `+`한 키워드는 24시간 뒤 사라지고, 같은 키워드는 한 번만 `+`한다(4.5).
- 키워드 상태는 💤비활성 / 🔥활성 / ⛔금지 세 가지다. 외부 데이터에서 확인되거나 가진 사람이 3명 이상이면 🔥가 된다(4.7).
- 키워드 점수: `trend_value = 소스 가중치(외부 2, 내부 1) × (10 + 40 × g(가진 사람 수))`, 점수는 `trend_value × 0.5`다. g는 1,000명에서 1이 되는 로그-선형 곡선이다(4.8).
- 현재 유행도(플레이어 점수) = `min(EXP, 100)` + 내 🔥 키워드 점수의 합. 키워드의 값이 바뀌면 보유자의 점수와 원 크기가 실시간으로 바뀐다(4.8, 9.2).
- 원 크기: 반지름 16~600px(최대 지름은 기준 맵 한 변의 10%). 커질수록 화면이 줌아웃된다(4.2, 4.8).
- EXP는 `+` 횟수로만 쌓인다(1회 = 1 EXP). 레벨은 1~100이고 레벨별 필요 EXP는 DB(`levels`)에서 관리한다(4.9).
- 충돌: 현재 유행도가 낮은 쪽이 키워드 하나를 잃는다(4.3). 랭킹은 현재 유행도 순서로만 정한다(4.14).
- 칭호는 누적 `+` 횟수, 레벨, 보유 키워드 수, 현재 유행도, 댓글 점수로 만든다(4.10).
- 급상승 목록과 키워드 순위는 공개하지 않는다(3.3).

## 2. 플레이 흐름

```
접속 → 메인 화면 → [시작] 또는 [Google로 계속하기] → 닉네임 → 아레나 입장
→ 검색창에 키워드 입력 → 트렌드 값 확인 → [+] → 내 트렌드 키워드에 추가, 아이콘 커짐
→ 다른 플레이어와 충돌(큰 쪽이 밀어냄) → 24시간 뒤 `+`가 사라지면 새 유행을 찾아 다시 검색
(검색 결과가 없는 새 단어도 바로 `+`할 수 있다.
 외부 데이터에서 사라지고 가진 사람도 3명 미만인 키워드는 💤비활성으로 잠들고, 다시 뜨거나 3명이 모이면 깨어난다)
```

## 3. 화면

### 3.1 메인 화면

```
┌──────────────────────────────────────────────────────────────┐
│  (배경: 원들이 떠다니며 커졌다 작아지는 아레나 애니메이션)            │
│                         Trendist                             │
│                  유행을 아는 자, 커진다.                          │
│     남들보다 먼저 뜨는 키워드를 찾아 +하고, 내 원을 키워 보세요.        │
│        🔍 키워드 찾기   →   ➕ 먼저 +하기   →   ⭕ 원이 커진다          │
│                    ┌──────────────────────┐                  │
│                    │        시작          │                  │
│                    └──────────────────────┘                  │
│                    ┌──────────────────────┐                  │
│                    │ G  Google로 계속하기   │                  │
│                    └──────────────────────┘                  │
│          로그인하면 다른 기기에서도 기록이 이어져요                   │
│   지금 1,284명이 플레이 중   [공지] [가이드] [이용약관] [개인정보]    │
└──────────────────────────────────────────────────────────────┘
```

- 메인 화면은 로그인하지 않은 사용자에게만 보인다. 갱신 토큰이 유효한(마지막 접속 후 1일 안) 로그인 사용자는 접속하면 메인 화면 없이 저장된 닉네임·나라로 바로 게임 화면에 들어간다.
- [시작]은 로그인 없이 게스트로 시작한다(이때 게스트 행과 방문자 ID가 만들어진다). [Google로 계속하기]는 로그인 후 바로 게임 화면으로 들어간다(그 나라에서 처음이면 닉네임부터 정한다. 탈퇴한 계정이면 복구 여부를 먼저 묻는다, 4.1).
- 게스트 첫 방문은 닉네임 입력과 나라 확인을 한 화면에서 하고 입장한다. 게스트 재방문은 저장된 닉네임·나라로 바로 입장하고, [설정] 링크로 바꿀 수 있다.
- 배경 애니메이션은 미리 만든 연출이고 실제 키워드를 쓰지 않는다. `prefers-reduced-motion`이면 정지 이미지로 바꾼다.
- 새 공지 팝업(4.16)은 게스트는 이 화면에서, 로그인 사용자는 게임 화면에 처음 들어올 때 뜬다. 방이 가득 차면 "지금은 접속자가 가득 찼어요"를 보여 준다.
- 모바일은 세로로 쌓고, 키보드로 [시작] → [Google로 계속하기] 순서로 이동할 수 있게 한다.

### 3.2 게임 화면

```
┌──────────────────────────────────────────────┬──────────────────────────┐
│ [랭킹 ▾] [공지] [가이드]  현재 접속 42명          │ [검색] [내 트렌드 키워드] [랭킹] │
│                                              │ ┌──────────────────────┐ │
│          ●민수(큰 원)                         │ │ 양쯔깐루▏              │ │
│                      ●유나                    │ └──────────────────────┘ │
│    ●나(조작 중)                  ●지훈          │ 양쯔깐루  🔥활성          │
│                                              │ 트렌드 67 · 👥 1,204명    │
│                                              │ 지금 +34점   [ + ]        │
│ [채팅 로그]                                    │ ──────────────────────── │
│ 유나: 양쯔깐루 지금 +하면 이득임                  │ 내 유행도 148 · 🐻 5레벨   │
│ [입력창____________________] [Google 로그인]   │                          │
└──────────────────────────────────────────────┴──────────────────────────┘
```

- 모바일은 아레나가 전체 화면이고 검색·내 트렌드 키워드·랭킹·공지는 하단 시트로 올라온다.
- 아이콘이 커지면 화면이 조금씩 줌아웃된다(4.2).
- 내 닉네임이나 아이콘을 누르면 내 정보·꾸미기 패널이 열린다.
- 아레나 오른쪽 위에 [공지사항] [가이드·FAQ] [미니맵(M)] [?] 버튼을 둔다. 공지사항(4.16)과 가이드·FAQ(4.17)는 게임 위에 창으로 열리고 게임은 멈추지 않는다.
- [?]는 조작 설명 카드(클릭·탭 이동, 방향키·WASD, 검색 → `+`, M 미니맵)를 펼치고 접는다. 처음 들어오면 펼쳐져 있고, 접으면 그 브라우저에 기억해서 다음부터는 접힌 채로 시작한다. 카드에서 가이드로 바로 갈 수 있다.

### 3.3 급상승 키워드 비노출
지금 뜨는 키워드를 보여 주면 모두가 같은 키워드를 따라 `+`해서 안목을 겨루는 의미가 사라진다. 그래서 다음은 두지 않는다.
- 실시간 급상승 목록, 키워드 랭킹, 검색 자동완성·추천 검색어, 키워드 이름을 단 NPC 봇, 메인 화면 배경의 실제 키워드(관리자 화면의 트렌드 키워드 목록, 13.6은 `ROLE_ADMIN`만 본다)

사용자가 직접 찾거나 사람끼리 공유한 정보는 보여 준다: 직접 검색한 키워드의 카드(활동 그래프 포함)와 트렌드 값·점수·인원, 다른 플레이어 팝업의 상위 3개 키워드(4.11), 채팅의 `#키워드`(4.13). 트렌드 상자(4.19)는 상자를 직접 연 사람에게만 키워드 하나를 잠깐 보여 주는 예외다.

## 4. 게임 규칙

### 4.1 입장과 계정

방문자 ID와 로그인
- 사용자 행은 [시작]이나 구글 로그인을 누를 때 만든다. 게스트는 이때 서버가 방문자 ID(`yyyyMMddHHmmss-UUID`, UTC)를 발급하고 쿠키에 담는다. 메인 화면만 보고 떠난 방문자는 방문자 ID도 사용자 행도 남기지 않는다. 게스트와 로그인 사용자가 같은 사용자 행 체계를 쓴다.
- 쿠키는 1년이고 재방문해도 연장하지 않는다. 만료 30일 전부터 로그인 안내를 보여 준다. 쿠키를 지우거나 다른 브라우저로 와서 다시 [시작]하면 새 ID와 새 게스트 행을 받는다.
- 방문자 ID는 인증 수단이므로 다른 사용자에게 보내지 않는다. 화면에는 닉네임만 보여 준다. 다른 플레이어는 방 안에서만 쓰는 세션 엔티티 번호로 가리키고, 사용자 내부 번호(`users.id`)도 다른 사용자에게 보내지 않는다.
- 구글 로그인은 선택이다. 로그인하면 현재 기록이 계정에 연결되어 다른 기기에서도 이어진다. 이미 다른 기록이 연결된 계정이면 계정 쪽을 우선하고 게스트 기록은 합치지 않는다. 구글 이름·이메일·사진은 쓰지 않는다.
- 로그인해야 하는 기능은 이미지 업로드, 픽셀 그림, 댓글 작성뿐이다. 채팅, 새 키워드 `+`, 댓글 투표는 게스트도 할 수 있다.
- 서버의 기록은 기간 제한 없이 보관한다.

닉네임
- 1~10자(NFC 정규화 후 화면에 보이는 글자 단위). 중복을 허용하고 태그를 붙이지 않는다. 내부에서는 항상 사용자 ID로 구분한다.
- 허용: 영문·숫자·공백·`_` `-` `.`, 그리고 한 가지 문자권(한글 / 일본어 가나·한자 / 한자 / 데바나가리). 문자권을 섞을 수 없다(`민수abc` 가능, `민수たろう` 불가). 전각 영숫자는 반각으로 바꾸고, 앞뒤 공백은 지우고 연속 공백은 하나로 줄인다.
- 금지

| 문자 | 이유 |
|---|---|
| `#` `@` | 채팅의 `#키워드`, 멘션과 혼동 |
| `<` `>` `&` `"` `'` `` ` `` `/` `\` | XSS, 경로·이스케이프 문제 |
| `: ; , { } [ ] ( ) = + * % $ ! ? ~ ^ \|`, 첫 글자 `-` | 링크 파싱, 로그·CSV 인젝션 |
| 제어·보이지 않는·방향 제어 문자 | 화면 깨짐, 같은 모양 닉네임으로 사칭 |
| 결합 문자 남용, 한글 자모 단독, 이모지, 허용 밖 문자권 | 렌더링 번짐, 비슷한 글자로 사칭 |

- 거부할 때 문제 글자를 알려 준다("닉네임에 쓸 수 없는 문자가 있어요: #"). 서버 검사 결과만 믿고, 화면에는 항상 텍스트로만 그린다.
- 예약어 제한은 없다. 진짜 관리자는 닉네임 옆 관리자 배지로 구분한다.
- 변경은 마지막 변경 후 1시간이 지나야 할 수 있다(설정값). 처음 정하는 것은 변경으로 세지 않는다. 닉네임은 나라마다 따로 정하고 변경 간격도 나라별로 센다. 새 나라에 처음 들어가면 마지막으로 쓴 닉네임을 미리 채워 보여 주고, 바꿀 수 있다.
- 금지 닉네임: 관리자가 등록한 단어가 닉네임에 들어 있으면 막는다(대소문자·공백·전각 무시). 욕설 목록도 여기서 관리한다. 이미 쓰던 닉네임이 금지되면 그 나라에 다음 입장할 때 바꿔야 하고(이때는 1시간 제한 없음), 접속 중이면 임시 이름 `플레이어`로 바뀐다.

탈퇴와 복구
- 탈퇴하면 DB의 값은 바꾸지 않고 `users.user_state_id`를 탈퇴 상태로 바꾸고 `users.deleted_at`에 시각만 기록한다. 닉네임, 꾸미기, 칭호, 댓글, 내 트렌드 키워드 등 저장된 값은 그대로 두고, 갱신 토큰은 모두 폐기한다.
- 화면에 보여 줄 때만 덮어쓴다: 닉네임은 `탈퇴한 사용자`, 아이콘은 기본 아이콘, 칭호는 숨김, 댓글 본문은 "탈퇴한 사용자의 댓글이에요".
- 랭킹·방·정보 팝업에서 빠지고, 남은 내 트렌드 키워드는 점수 산정에서 제외한다(24시간 뒤 평소대로 삭제).
- 복구: 탈퇴한 계정과 같은 구글 계정(같은 `oauth_id`)으로 다시 로그인하면 "탈퇴한 계정이에요. 복구할까요?"를 보여 주고, [복구]를 눌렀을 때만 복구한다. 복구하면 상태를 정상으로 되돌리고 `deleted_at`을 비우며 로그인된다. 닉네임, 레벨, EXP, 칭호, 꾸미기, 댓글은 탈퇴 전 그대로 돌아오고, 탈퇴 중에 만료된 `+`는 평소대로 삭제되어 있다. [취소]하면 아무것도 바꾸지 않고 로그인되지 않으며, 게스트로 쓰던 중이면 그대로 게스트로 남는다.
- 방문자 ID(게스트)로는 복구되지 않는다. 탈퇴한 상태에서는 갱신 토큰도 방문자 ID도 세션을 만들지 못하고, 게스트가 같은 브라우저로 다시 오면 새 방문자 ID를 받는다.

### 4.2 아레나와 이동
- 아이콘은 원으로 고정이다. 닉네임은 원 바로 아래, 활성 칭호는 그 아래 작은 글씨로 항상 보인다.
- 조작
  - 빈 바닥 클릭(모바일 탭): 그 지점으로 이동하고 근처에서 감속해 멈춘다. 이동 중에 다시 찍으면 이전 목표는 취소되고 새 지점으로 바로 바뀐다(방향키 이동 중이어도 목표 이동으로 바뀐다). 클릭한 지점에는 물결 띠 두 개가 시차를 두고 바깥에서 안쪽으로 모여들며 사라지는 효과를 보여 준다(약 0.9초, `prefers-reduced-motion`이면 제자리에서 옅어지는 링 하나).
  - 방향키·WASD: 직접 이동. 목표를 해제한다. 모바일은 가상 조이스틱도 쓴다.
  - 다른 아이콘 클릭: 정보 팝업(4.11). 내 아이콘 클릭: 내 정보·꾸미기 패널.
  - 마우스를 따라가는 방식은 쓰지 않는다. 클릭 이동은 초당 10회까지(세밀하게 방향을 바꿀 수 있게), 방향키 입력은 초당 5회까지 서버로 보낸다. 그 사이에 찍은 지점은 버리지 않고 마지막 지점을 보낸다.
- 충돌 후 목표: 밀어낸 큰 쪽은 유지, 밀려난 작은 쪽은 해제, 비슷한 크기라 같이 튕기면 둘 다 해제.
- 정지: 조작하지 않으면(창 포커스를 잃어도) 감속해서 그 자리에 멈춘다. 자동으로 떠다니지 않는다.
- 시점: 내 아이콘을 항상 화면 가운데에 둔다. 아이콘이 커질수록 화면을 조금씩 줌아웃한다(배율 = 1 / (1 + (반지름 − 16) / 170), 반지름 45px → 0.85, 104px → 0.66, 308px → 0.37, 600px → 0.23). 배율은 반지름처럼 0.5초에 걸쳐 부드럽게 바뀐다. 아레나 바깥은 어둡게 칠하고 벽 경계선을 그린다.
- 바닥 격자: 50px마다 1px 선, 250px마다 2px 선. 짙은 회청색 바닥에 약 15% 투명도의 밝은 선. 아레나 바깥에는 격자가 없다.
- 가시성: 모든 아이콘에 테두리와 옅은 그림자를 그린다. 바닥과 대비가 낮은 색은 고를 수 없고 색에 투명도를 받지 않는다. 내 아이콘에는 흰색 링을 하나 더 그린다.
- 크기 변화는 0.5초에 걸쳐 부드럽게 바뀐다.
- 방: 나라마다 하나, 최대 1000명이다. 차면 입장을 막고 대기열은 두지 않는다. 월드는 1000명 기준 약 12,000×12,000px이고 인원이 적으면 활동 영역을 좁힌다. 밀도가 낮은 곳에 스폰하고, 미니맵에 큰 아이콘 상위 20명과 내 위치를 보여 준다.

### 4.3 충돌

| 상황 | 결과 |
|---|---|
| 반지름 비율 1.15 미만 | 서로 반발하며 같이 튕긴다 |
| 비율 1.15 이상 | 작은 쪽만 충돌 방향으로 크게 튕긴다. 큰 쪽은 반동 없음 |
| 튕김 세기 | 반지름 비율에 비례(상한 3배), 0.4초에 걸쳐 감속 |
| 같은 상대 연속 충돌 | 0.5초 쿨다운 |
| 최대 속도 | 크기와 관계없이 모든 아이콘이 같다(기본 240px/s, DB 설정값). 충돌의 결과는 크기가 가른다 |

- 튕겨도 탈락하지 않는다. 가장자리는 벽이고 추락 구역은 없다.

충돌로 키워드 잃기
- 두 플레이어가 부딪히면 현재 유행도가 낮은 쪽이 내 트렌드 키워드 중 하나를 무작위로 잃는다. 크기(반지름 비율)와 관계없이 점수만 비교하고, 점수가 같으면 아무도 잃지 않는다.
- 잃는 후보: 내 트렌드 키워드 중 금지되지 않은 키워드 전부(💤 키워드 포함). 후보가 없으면 아무 일도 없다.
- 잃은 키워드는 목록에서 바로 지워지고 점수에서 빠진다. 바로 다시 `+`할 수 있고, 그때의 점수로 새로 더해지며 24시간도 새로 시작한다. 잃은 키워드를 다시 찾아 `+`하는 것 자체를 상호작용으로 본다.
- 잃은 사람에게 "민수와 부딪혀 '양쯔깐루'를 잃었어요" 알림을 보낸다. 이긴 쪽에는 어떤 키워드인지 알려 주지 않고 보상도 없다.
- 보호 장치
  - 키워드를 잃은 사람은 상대와 관계없이 10초 동안 다시 잃지 않는다. 연속으로 털리는 것을 막는다.
  - 입장 직후 10초 동안은 잃지 않는다.
  - NPC 봇과의 충돌은 제외한다.
- 보호 시간은 관리자 설정이다(13.3).
- 판정은 항상 원의 반지름으로만 한다. 꾸미기는 판정에 영향이 없다.

### 4.4 키워드 검색과 `+`
1. 검색창에 입력하고 Enter 또는 검색 버튼을 누른다. 자동완성·추천은 없다.
2. 서버가 키워드를 정규화(4.18)해서 현재 나라에서 찾는다. 다른 나라의 같은 단어는 별개 키워드다.
   - ⛔금지: "검색할 수 없는 키워드예요"
   - 🔥활성·💤비활성: 결과 카드를 바로 보여 준다. 💤 키워드는 외부 소스를 다시 조회해서 외부에서 확인되면(관심도 10 이상) 그 자리에서 🔥활성으로 바꾼다.
   - DB에 없음: 외부 소스를 바로 조회한다. 확인되면 🔥활성 키워드로 등록하고, 아니면 다른 키워드와 같은 💤 카드와 `+` 버튼을 보여 준다. 첫 `+` 때 키워드를 만든다(4.6).
3. 결과 카드: 키워드명 옆에 `트렌드 67 · 👥 1,204명`(💤 키워드는 `💤 · 👥 2명`), 시간별 활동 그래프, 상태 배지, 지금 `+`하면 더해지는 점수(`+34점`)와 삭제 시각(24시간 뒤), 댓글, `+` 버튼(4.12). 트렌드 값(0~100)은 키워드의 현재 세기이고 👥 인원은 지금 이 키워드를 가진 사람 수다. 💤 키워드는 점수 대신 "3명이 모이거나 외부 트렌드에 잡히면 🔥활성이 돼요"를 보여 준다.
4. `+`하면 내 트렌드 키워드에 들어가고 그 키워드의 점수만큼 현재 유행도가 바로 올라 아이콘이 커진다. 아이콘 위에 `+N`이 뜬다. 💤 키워드는 `+`할 수 있지만 🔥가 되기 전까지 키워드 점수는 0점이다. EXP는 💤 키워드에도 바로 받는다(4.9).
5. 검색과 `+`는 그 키워드의 누적 카운터에 센다(9.9).

### 4.5 내 트렌드 키워드
내가 `+`한 키워드 목록이다. 하루 단위의 빠른 주기로 게임이 흘러가게 하기 위해 다음 규칙을 둔다.
- 같은 키워드는 한 번만 `+`한다. 목록에 있는 동안 그 키워드의 `+` 버튼은 비활성화된다.
- `+`한 지 24시간이 지나면 목록에서 자동으로 삭제되고, 그 뒤에는 다시 `+`할 수 있다. 충돌로 잃은 키워드(4.3)도 바로 지워진다.
- 목록 위에 지금 가진 키워드 개수(`players.hold_count`)를 보여 준다. 항목마다 키워드, 상태 배지, `+`한 시각, 지금 트렌드 값과 점수, 삭제까지 남은 시간(1시간 이내면 강조)을 보여 준다. 정렬은 최근 / 점수 / 남은 시간이고 즐겨찾기·폴더·메모는 없다.
- 삭제된 `+`의 기록은 남지 않는다. 누적 `+` 횟수(`total_plus_count`), EXP, 댓글 점수는 누적값으로 남고, 키워드 쪽에는 누적 `+` 수와 누적 검색 수가 남는다(9.9).
- 키워드가 ⛔금지되면 모든 사용자의 목록에서 조회되지 않고 점수 산정에서 제외된다(데이터는 그대로 둔다).

### 4.6 새 키워드
검색해도 없는 신조어·밈도 별도 등록 절차 없이 `+`할 수 있다.

흐름
1. 검색 결과가 없거나 외부 관심도가 10 미만이면 💤 카드와 `+` 버튼을 보여 주고(4.4), 첫 `+` 때 키워드가 💤비활성으로 만들어진다. 💤 키워드도 누구나 `+`할 수 있고 키워드 점수만 0점이다.
2. 그 키워드를 가진 사람이 3명이 되거나(내부 확산) 외부 관심도 10 이상이 확인되면(외부 확인) 즉시 🔥활성이 된다. 둘 중 하나만 충족하면 된다.
3. 🔥가 되는 순간 키워드를 가진 사람(💤일 때 `+`해서 아직 24시간이 안 지난 사람)은 즉시(접속 중이 아니면 최대 1분 안에) 그 키워드의 점수를 받는다. 외부에서 확인된 키워드는 가진 사람이 없어도 기본 점수를 받고, 사람만으로 활성된 키워드는 가중치 1이 적용되어 외부 키워드(가중치 2)의 절반 점수에서 시작한다(4.8). 사람 수에 따른 증가가 완만해서 여러 계정 담합으로 얻는 점수가 작다.
4. 외부 데이터에 없고 가진 사람도 3명 미만이 되면 💤비활성이 된다(4.7).

등록 조건
- 게스트를 포함한 모든 사용자, 비용·한도 없음.
- 20자 이하(입력한 글자 기준). 최소 길이 제한은 없어서 한 글자 키워드도 된다. 영문·숫자·공백과 지원 언어의 문자(한글, 가나, 한자, 데바나가리). 그 지역 문자가 아니어도 된다.
- 정규화(4.18) 뒤에도 한 번 더 검사한다: 허용 문자만 남았는지, 비어 있지 않고 100자 이하인지(NFKC가 `㈱` → `(株)`처럼 글자를 늘리거나, 공백만 있는 입력이 비는 경우를 거른다). 통과하지 못하면 거부한다.
- URL·전화번호·이메일 등 개인정보 패턴, 차단어, 민감 키워드, 실존 인물 이름 패턴은 쓸 수 없다.

### 4.7 키워드 생존주기

```
(없음) ──검색, 외부 관심도 10 이상──→ 🔥활성 (반영 소스 = 그 외부 소스)
(없음) ──첫 `+`(외부 데이터 없음 또는 10 미만)──→ 💤비활성 (반영 소스 = internal)
💤비활성 ──가진 사람 3명 이상 또는 외부 관심도 10 이상──→ 🔥활성 (즉시)
🔥활성 ──외부 데이터가 사라짐──→ 반영 소스가 internal로 바뀜. 가진 사람 3명 미만이면 💤비활성 (즉시)
어느 상태든 ──관리자 금지──→ ⛔금지 ──해제──→ 💤비활성
```

| 상태 | 의미 | `+` | 검색 | 점수 | 정기 수집 |
|---|---|---|---|---|---|
| 💤 비활성 | 아직 활성 전이거나, 외부 데이터에서 사라지고 가진 사람도 3명 미만이라 잠든 키워드 | O | O | 0점 | 최근 30일 안에 `+`가 있었을 때만 |
| 🔥 활성 | 외부 관심도 10 이상 또는 가진 사람 3명 이상 | O | O | O | O |
| ⛔ 금지 | 관리자가 금지한 키워드 | X | X | 제외 | X |

- 상태는 `keyword_states` 테이블(활성 / 비활성 / 금지)로 구분한다. 애플리케이션이 시작할 때 이름으로 번호를 찾아 두고 코드에서 상수로 쓴다. 새 상태는 이 테이블에 행을 추가하고 전이 코드를 쓰면 된다.
- 키워드는 지우지 않는다. 같은 단어는 항상 같은 키워드로 이어져 활동 기록·댓글이 남는다. 개인정보·법적 문제가 있을 때만 관리자가 완전히 지운다.
- 반영 소스(`keywords.data_source_id`)는 점수의 가중치를 정하는 소스다. 외부 데이터에서 확인되면 그 나라의 외부 소스(KR은 네이버 데이터랩, 해외는 BigQuery), 아니면 `internal`이다(10.3).
- 💤 → 🔥 전환은 `+`할 때(인원 확인), 검색 때 외부 재조회, 매일 정기 수집 때 판정하고 바로 바꾼다.
- 🔥 → 💤 전환은 한 가지 경로뿐이다: 반영 소스가 외부였던 키워드가 이번 수집에서 모든 외부 소스에서 값이 없고 가진 사람도 3명 미만일 때. 외부 데이터가 있는 한 관심도가 10 아래로 떨어져도, `+`가 오래 없어도 🔥를 유지한다. 거대 플랫폼의 외부 데이터를 사용자 수보다 무겁게 본다는 원칙이다. 판정 시점은 외부 값이 갱신될 때와 가진 사람 수가 줄 때(24시간 삭제, 충돌로 잃기)다.
- 유행이 식는 것은 별도 상태가 아니라 가진 사람 수 감소로 나타난다. 외부 키워드의 점수는 기본값 아래로 내려가지 않는다(4.8).
- 금지된 키워드는 내 트렌드 키워드와 댓글 데이터를 지우지 않고, 조회되지 않게 하고 점수 산정에서 제외한다. 해제하면 💤비활성으로 돌아간다.

### 4.8 점수
이 절의 숫자는 모두 기본값이고 관리자가 바꿀 수 있다(13.3).

키워드 트렌드 값 (`keywords.trend_value`, 0~100)

```
g(n)        = log10(1 + min(n, 1000) / 30) / log10(1 + 1000 / 30)     // n = 가진 사람 수. 0명에서 0, 1,000명(방 인원 상한)에서 1
trend_value = 🔥활성이면 w × ( 10 + 40 × g(n) ), 💤·⛔이면 0
              w = 반영 소스의 가중치(외부 소스 2, internal 1)
키워드 점수  = trend_value × 0.5                                       // 키워드 하나가 더하는 점수. 외부 10~50, 내부 5~25
```

| 가진 사람 n | 0 | 1 | 3 | 10 | 30 | 100 | 300 | 1,000 이상 |
|---|---|---|---|---|---|---|---|---|
| g(n) | 0 | 0.009 | 0.027 | 0.081 | 0.196 | 0.415 | 0.678 | 1 |
| 외부 키워드(w=2) trend_value | 20.0 | 20.7 | 22.2 | 26.5 | 35.7 | 53.2 | 74.2 | 100 |
| 외부 키워드 점수 | 10.0 | 10.4 | 11.1 | 13.3 | 17.8 | 26.6 | 37.1 | 50 |
| 사람만 있는 키워드(w=1) trend_value | 💤 | 💤 | 11.1 | 13.3 | 17.8 | 26.6 | 37.1 | 50 |
| 사람만 있는 키워드 점수 | 0 | 0 | 5.5 | 6.6 | 8.9 | 13.3 | 18.6 | 25 |

- 가진 사람이 많을수록 높다. 적을 때는 가진 사람 수에 거의 비례하고(처음 한 명당 trend_value가 외부 약 0.75, 내부 약 0.38), 많아질수록 로그처럼 완만해진다(300명 구간은 한 명당 약 0.07, 0.03). 식의 30은 "로그 완만도"로, 1에 가까울수록 순수 로그, 클수록 선형에 가깝다.
- 외부에서 확인된 키워드는 가진 사람이 없어도 20(점수 10)에서 시작해서 첫 `+`가 0점이 되지 않는다. 사람만으로 활성된 키워드는 3명이 되어야 시작하고 점수는 외부의 절반이다.
- 식의 10은 기본 비율, 50은 최대 기준값이다. 가중치가 최대 2라서 trend_value는 구조적으로 100을 넘지 않는다.
- 외부 데이터의 크기(순위·상대 비율)는 점수에 들어가지 않고 외부 확인(관심도 10 이상)과 반영 소스를 정하는 데만 쓴다.
- 트렌드 값은 가진 사람 수(`holder_count`)가 바뀔 때(`+`, 24시간 삭제, 충돌로 잃기), 반영 소스나 상태가 바뀔 때, 가중치·설정이 바뀔 때 다시 계산해서 저장한다.

현재 유행도 (플레이어 점수. 아이콘 크기를 정하는 값, `players.current_score`)

```
현재 유행도 = min(EXP, 100) + Σ 내 트렌드 키워드의 점수   // 키워드는 🔥활성만, 💤·⛔는 0
```

- `+`하는 순간 EXP +1과 그 키워드의 새 점수가 바로 더해진다. EXP 점수는 줄지 않아서, 오래 플레이한 사람은 키워드가 모두 만료돼도 100점(반지름 최소 약 45px)이 남는다.
- 내가 `+`한 키워드에 사람이 몰리면 내 원도 함께 커지고 사람이 빠지면 작아진다. 키워드의 트렌드 값이 바뀌면 그 키워드를 가진 접속 중인 모든 플레이어의 점수와 원 크기가 실시간으로 바뀐다(9.2). 접속 중이 아닌 플레이어는 DB에서 1분 안에 다시 합산하고, 1시간마다 전원을 점검한다(9.4).
- 매일 새 유행을 찾아 `+`해야 크기를 유지한다. `+` 횟수 제한(에너지, 슬롯)은 없다. 점수가 무한히 쌓이지 않게 하는 장치는 24시간 삭제, 같은 키워드 1회, 💤 키워드 0점, EXP 점수 상한 100, 크기 상한이다.

크기

```
radius    = 16 + 584 × min(현재 유행도, 2000) / 2000    // px. 최대 600px = 지름 1,200px = 기준 맵 한 변(12,000px)의 10%
zoom      = 1 / (1 + (radius − 16) / 170)               // 화면 배율(4.2)
```

| 현재 유행도 | 0 | 100 | 300 | 600 | 1,000 | 2,000 이상 |
|---|---|---|---|---|---|---|
| 반지름 | 16px | 45px | 104px | 191px | 308px | 600px |
| 지름 / 맵 한 변 | 0.3% | 0.8% | 1.7% | 3.2% | 5.1% | 10% |
| 키워드 20점 `+` 한 번 | +36% | +13% | +5.6% | +3.1% | +1.9% | 변화 없음 |

- 점수 1점에 반지름 0.292px이다. 키워드 점수 15점짜리 `+`는 약 4px, 50점짜리는 약 15px 커진다. 작을 때는 키워드 하나로 크게 변하고, 클 때는 키워드가 여러 개 겹쳐 바뀔 때 눈에 띈다.
- 최대 속도는 크기와 관계없이 모든 플레이어가 같고(기본 240px/s) `settings`의 값이다(13.3). 줌아웃 때문에 화면에서는 큰 아이콘이 더 천천히 움직여 보인다.
- 상한은 현재 활동 영역이 아니라 기준 맵(12,000px)으로 고정해서 인원이 바뀌어도 모두의 크기가 한꺼번에 바뀌지 않는다. 상한(2,000점)은 EXP 점수 100에 점수 50짜리 키워드 약 38개를 더한 값이고, 베타에서 실제 점수 분포를 보고 조정한다.

### 4.9 레벨, 성장 아이콘, 꾸미기

레벨과 EXP (플레이어 단위, 나라마다 따로, 줄지 않음)
- EXP는 `+` 횟수로만 쌓인다. `+` 한 번 = 1 EXP이고 `+`한 순간 바로 준다(💤 키워드 포함). 다른 행동으로는 주지 않는다. 즉각 반응을 주고 활동량을 늘리려는 선택이다.
- 레벨은 1~100이다. 레벨별 필요 누적 EXP는 DB의 `levels` 테이블에 두고 관리자가 바꾼다(13.4). 기본값은 다음과 같다.

| 레벨 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 | 10 |
|---|---|---|---|---|---|---|---|---|---|
| 누적 EXP | 1 | 3 | 8 | 13 | 22 | 33 | 50 | 72 | 100 |

| 레벨 | 11 | 20 | 30 | 50 | 70 | 100 |
|---|---|---|---|---|---|---|
| 누적 EXP | 121 | 400 | 900 | 2,500 | 4,900 | 10,000 |

- 11~100레벨은 `100 × (레벨 / 10)²`를 반올림한 값이다. 하루 `+` 100번이면 30레벨까지 약 9일, 100레벨까지 약 100일이다(가정치).
- EXP는 현재 유행도에도 들어간다: `min(EXP, 100)`(4.8). 100 EXP(10레벨)에서 상한이고, 그 이상은 레벨만 오른다.
- 레벨이 오르면 알림을 보여 준다. 정보 팝업과 내 정보에 레벨과 다음 레벨까지 남은 EXP를 보여 준다. 새 나라에서는 1레벨부터 시작한다.

성장 아이콘 (1~10단계)
- 모든 플레이어는 같은 캐릭터가 레벨에 따라 자라는 아이콘을 쓴다. 캐릭터는 지금은 거북이로 시작한다(동물이나 밈 캐릭터로 바꿀 수 있다, 16.2). 1레벨은 단순한 테두리와 단일 배경색이라 얼굴처럼 보이지 않고, 레벨이 오를수록 눈·코·입 같은 부위와 캐릭터의 형태가 흐릿하게 생기다가 점점 선명해져 10레벨에서 뚜렷하게 완성된다. 얼굴 부위는 원 안에만 그린다. 11레벨 이후는 모습이 그대로이고 레벨 숫자만 오른다.
- 바탕색은 그 캐릭터에 맞춰 정해진 색 하나다(무작위가 아니다). 그래서 꾸미기가 열리기 전(11레벨 전)에는 같은 레벨의 모든 사용자가 같은 모습이고, 닉네임과 내 아이콘의 흰색 링(4.2)으로 구분한다.
- 10레벨까지는 레벨이 오를 때 새 부위가 그려지는 연출을 보여 준다.

꾸미기 (11레벨부터, 해금 레벨은 설정값)

| 방식 | 대상 |
|---|---|
| 색: 프리셋 24색 + 직접 선택(HEX), 테두리 색 | 11레벨 이상 모든 사용자 |
| 테두리 두께(범위는 13.3) | 11레벨 이상 모든 사용자 |
| 직접 그린 픽셀 그림 | 11레벨 이상 로그인 사용자 |
| 직접 올린 이미지 | 11레벨 이상 로그인 사용자 |

- 꾸미기는 프로필(`profiles`)로 관리한다. 프로필 하나는 종류(`profile_type`: 성장형 `GROWTH` / 직접 그린 픽셀 `PIXEL` / 업로드 이미지 `IMAGE`), 바탕색, 테두리 색, 테두리 두께를 담는다. 성장형은 11레벨 이상에서 색과 두께를 바꿀 수 있고 성장 캐릭터는 그대로 그려진다. 한 플레이어가 여러 개를 가질 수 있지만(`players` 1 : 프로필 N) 하나만 장착한다. 그 나라에 처음 들어가면 기본 프로필(성장형, 그 캐릭터에 정해진 바탕색)이 만들어져 장착된다. 프리셋 24색은 DB가 아니라 설정(코드)으로 관리하고, 색은 모두 HEX 값으로 저장한다. 픽셀 그림과 업로드 이미지는 로그인했을 때만 바꿀 수 있다(서버가 확인한다). 프로필은 플레이어당 최대 10개이고, 넘으면 장착하지 않은 가장 오래된 것부터 지운다(13.3).
- 이미지 업로드: PNG·JPG·WebP 최대 2MB → 원형 크롭 → 서버가 128×128 WebP로 줄이고 메타데이터 제거, 원본은 보관하지 않는다. 투명한 부분은 바탕색으로 채운다. 자동 검열(13.5)을 통과해야 저장한다.
- 픽셀 그림: 로그인 사용자가 격자(크기와 색 수는 16.2)에 직접 그린다. 서버가 이미지 파일로 저장하고 업로드 이미지와 같은 검열·신고·제재를 적용한다. 픽셀 그림과 업로드 이미지 파일은 프로필 번호로 찾는다(`profiles/{profile_id}`). 같은 프로필을 다시 저장하면 주소 끝에 `image_changed_at`을 붙여(`?v=...`) 옛 이미지가 남지 않게 한다.
- 제한: 픽셀 그림·이미지 변경 1시간에 1번, 색·두께 변경 5초에 1번(플레이어별로 센다). 픽셀 그림·이미지 변경은 서버를 다시 켜도 유지되도록 DB의 변경 시각(`profiles.image_changed_at`)으로 확인하고, 색·두께 변경은 요청 빈도 제한(9.5)으로 처리한다.
- 디자인 복사: 같은 방 플레이어의 정보 팝업(4.11)에서 [디자인 복사]를 누르면 그 사람이 장착한 프로필(`profile_id`)을 따라 한다. 바탕색, 테두리 색, 테두리 두께를 내 새 프로필(성장형)로 복사해 장착하고, 픽셀 그림과 업로드 이미지는 복사하지 않는다(상대가 `PIXEL`·`IMAGE` 프로필이어도 색과 두께만 가져온다). 복사하는 순간의 값을 가져오므로 상대가 나중에 바꿔도 내 프로필은 변하지 않는다. 내 레벨이 11 미만이면 할 수 없고, 색 변경 제한을 따른다.
- 금지 이미지: 성적·폭력·혐오 표현, 타인 얼굴 사진, 타인 저작물, 개인정보. 위반이면 그 프로필을 지우고 성장형 기본 프로필로 되돌리고, 반복하면 업로드를 정지한다.
- 닉네임 글자색은 배경 밝기에 따라 흰색·검정을 고르고 외곽선을 둔다. 작은 아이콘에서는 말줄임표로 줄인다.

### 4.10 칭호
- 조건을 달성하면 자동 지급되고 알림이 온다. 한 번 받은 칭호는 잃지 않는다. 칭호는 나라마다 따로 받고, 그 나라의 수치로 판정한다.
- 그 나라에서 보유한 칭호 중 최대 1개를 활성화해 닉네임 아래에 표시한다. 새로 얻어도 자동 활성화하지 않는다. 변경은 5초에 1번.
- 칭호와 조건은 모두 `titles` 테이블의 데이터(DB 값)다. 운영 중에 코드 배포 없이 추가·수정할 수 있고(13.4), 아래 목록은 처음 넣는 예시다. 칭호 ID는 아래 순서대로 넣어 정해진다(번역 키, 8절).
- 칭호함에서 보유 칭호, 획득일, 아직 못 얻은 칭호의 조건과 진행률을 볼 수 있다.

조건 쓰는 법: `titles.condition_type`과 `condition_params`(JSON)

| condition_type | condition_params | 뜻 | 판정 시점 |
|---|---|---|---|
| METRIC | `{"metric": "total_plus_count", "gte": 100}` | 플레이어 수치가 기준값 이상 | 그 값이 바뀔 때 |
| RANK | `{"metric": "current_score", "within": 10}` | 그 나라 순위가 N위 안 | 랭킹 갱신(1분) |

- `metric`으로 쓸 수 있는 값은 `players`의 `total_plus_count`(누적 `+` 횟수), `level`, `hold_count`(지금 가진 키워드 수), `current_score`(현재 유행도), `comment_score`(댓글 점수)다. 새 지표가 필요하면 `players`에 컬럼을 추가하고 `metric` 이름만 늘린다.
- 현재 유행도에는 EXP 점수 100이 들어 있어서 "현재 유행도 100"은 키워드 없이도 달성된다. 그래서 점수 조건은 500부터 시작한다.

### 4.11 다른 플레이어 정보 팝업
- 다른 아이콘을 클릭하면 열린다: 아이콘·닉네임(관리자 배지)·활성 칭호, 현재 유행도·레벨·댓글 점수, 최근 7일 점수 그래프, 그 사람의 내 트렌드 키워드 중 점수 상위 3개(이름, 상태 배지).
- 키워드 이름과 상태만 공개한다. 점수·시각은 숨긴다. 숨기기 설정은 없고 공개 범위를 개인정보 처리방침에 적는다.
- 키워드 이름을 누르면 키워드 상세 카드(4.12)가 열려 바로 `+`할 수 있다.
- [디자인 복사]: 그 사람의 꾸미기를 내 꾸미기로 가져온다(4.9). 11레벨 전에는 비활성으로 두고 "11레벨부터 쓸 수 있어요"를 보여 준다.
- 바깥 클릭·ESC·닫기로 닫는다. 게임은 멈추지 않는다. 모바일은 하단 시트.

### 4.12 키워드 상세 카드와 댓글
키워드 이름이 보이는 모든 곳(검색 결과, 내 트렌드 키워드, 정보 팝업, 채팅 `#키워드`)에서 같은 카드가 열린다. 뜻과 유행 이유는 사용자 댓글로만 전달한다.

```
┌──────────────────────────────────────────┐
│ 양쯔깐루  🔥활성 트렌드 67            [ + ]  │
│ 👥 1,204명 · 누적 + 4,321 · 검색 12,030    │
│ [활동]  24시간 7일 30일 180일  ━검색 ━+    │
│ ─ 댓글 128 ─────────────────────────────  │
│ 🥇 망고·자몽에 요거트 올린 홍콩 디저트예요 (👍 41) │
│ 🥈 편의점에서 컵으로 나와서 뜬 듯 (👍 23)         │
│ 🥉 여름 신메뉴로 카페마다 나오는 중 (👍 12)       │
│ ─ 최신순 ───────────────────────────────  │
│ 유나 · 3분 전: 어제 먹어봤는데 생각보다 달아요     │
│            ‹ 1 2 3 … 7 ›                     │
│ [댓글 쓰기]                         [신고]     │
└──────────────────────────────────────────┘
```

댓글
- 작성은 로그인 사용자만, 5~200자, 링크·전화번호 불가, 한도 없음. 수정은 5분 이내, 삭제는 언제든(소프트 삭제). 대댓글은 2차.
- 투표: 게스트 포함 누구나 댓글당 1표(👍/👎), 자기 댓글과 삭제·탈퇴 댓글은 불가. 같은 버튼을 다시 누르면 취소, 반대 버튼은 변경. 추천·비추천 수는 모두 공개.
- 정렬: 추천 상위 3개(추천 1개 이상, 동점이면 먼저 쓴 것)를 🥇🥈🥉로 고정하고, 나머지는 최신순 20개씩 페이지로 보여 준다. 비추천은 순위에 영향이 없다. 접힘·숨김은 없다.
- 표시: 삭제한 댓글은 "삭제된 댓글이에요", 탈퇴한 사용자의 댓글은 "탈퇴한 사용자의 댓글이에요". 본문은 DB에 그대로 두고 관리자만 볼 수 있다.
- 댓글 점수(`players.comment_score`): 댓글을 쓰면 +1, 삭제하면 −1, 내 댓글이 추천을 받으면 +1, 비추천을 받으면 −1이다. 0 아래로 내려가지 않는다(오차를 막고, 비추천으로 점수가 마이너스가 되어 기분이 나빠지지 않게 하려는 것이다). 투표가 바뀌거나 취소되면 반대로 되돌린다(추천 → 비추천은 −2). 댓글을 삭제해도 그 댓글이 이미 받은 추천·비추천 점수는 되돌리지 않는다(삭제는 −1만 한다). 0에서 막힌 뒤 그 비추천이 취소되면 실제보다 1 높아질 수 있지만 허용한다. 프로필과 칭호에만 쓰고 크기에는 반영하지 않는다. 내 댓글이 상위 3개에 들면 알림을 보낸다.
- 댓글이 없으면 "아직 댓글이 없어요. 이 유행을 몰랐던 사람을 위해 알려 주세요"를 보여 주고, "사용자가 쓴 의견이며 사실 확인은 되지 않았어요" 라벨을 단다.

활동 그래프
- 카드 가운데에 활동 그래프와 범위 선택 [24시간 | 7일 | 30일 | 180일]을 둔다(기본 24시간). 값은 `keyword_log_24h`(24시간)와 `keyword_log_dailies`(7일 이상)의 증분(9.9)이다. 24시간은 시간 단위, 7일·30일·180일은 하루 단위(나라 현지 날짜 기준) 점으로 그린다.
- 선: 검색 수, `+` 수. [가진 사람] 토글을 켜면 가진 사람 수를 오른쪽 축의 얇은 점선으로 겹쳐 보여 준다(기본 꺼짐). 카드 상단에 누적 `+` 수와 누적 검색 수도 보여 준다(`keywords.total_plus_count`, `search_count`).
- 느낌: 부드러운 곡선, 선 아래 옅은 그라데이션 면, 처음 열 때 왼쪽에서 오른쪽으로 그려지는 효과(`prefers-reduced-motion`이면 생략), 마우스·터치를 올리면 세로 안내선과 그 시간의 값 말풍선, 가장 높은 시간에 점과 "최고" 표시. 이번 시간은 집계 중이라 점선으로 그리고 끝점이 깜빡인다.
- 색만으로 구분하지 않게 선 모양(실선/파선)도 다르게 한다. 그래프 아래에 요약 문장("최근 24시간 검색 37회, `+` 12회, 오후 3시에 가장 많았어요")을 두고 표로 볼 수 있게 한다. 시간은 선택한 나라의 시간대로 보여 준다.
- 기록이 없으면 "아직 기록이 없어요"를 보여 준다. 키워드를 직접 연 사람에게만 보이고, 활동이 많은 키워드 목록이나 순위는 만들지 않는다(3.3).

### 4.13 채팅
- 나라 방 단위 전체 채팅. 게스트도 쓸 수 있다. 메시지 100자, 1초에 1회.
- [전체 | 근처] 탭. 근처는 내 화면 주변 사람의 메시지만 보여 준다. 말풍선은 보낸 사람 아이콘 위에 3초.
- `#키워드`를 누르면 검색창에 들어간다. 링크는 차단하고 욕설은 필터링한다. 신고와 차단(내 화면에서 숨김)을 둔다.
- 모든 메시지는 30일 보관하고 지운다(신고 처리 중인 메시지는 남김). 개인정보 처리방침에 적는다.

### 4.14 랭킹
- 나라별 사용자 랭킹은 현재 유행도(`players.current_score`) 순서로만 정한다. TOP 10을 보여 주고, 접속 중인 플레이어는 방 메모리 값으로 실시간, 그 밖의 플레이어는 DB 값(1분 캐시)으로 계산한다. 다른 나라 랭킹은 읽기만 한다. 키워드 랭킹은 두지 않는다.

### 4.15 점수 추이
- 나라별 현재 유행도를 1시간 단위로 기록하되, 플레이어마다 나라 현지 00시~23시 24칸에 덮어써서 최근 24시간만 남기고(`player_score_24h`, 행을 지우지 않는다), 하루 단위 기록(그날 마지막 값)은 영구 보관한다(`player_score_dailies`). 점수가 바뀐 시간만 기록한다. 이 테이블들은 그래프용 로그이고, 실시간 점수는 `players.current_score`에 있다.
- 내 프로필 "점수 추이" 탭: 24시간(시간 단위) / 7일 / 30일 / 전체(하루 단위). 선 그래프에 칭호 획득 시점 표시, 요약 문장("7일 전 120점 → 현재 148점").
- 다른 사용자는 정보 팝업에서 최근 7일(하루 단위)만 본다.

### 4.16 공지사항
- 관리자만 작성·수정·삭제한다. 모든 나라 공통이고 번역하지 않는다. 제목 1~50자, 본문 1~5000자(텍스트, URL 자동 링크). 상단 고정, 소프트 삭제, 수정 시 "수정됨" 표시.
- 팝업: 등록할 때 팝업 여부(기본 켬)와 기간(1~90일, 기본 7일)을 정한다. 메인 화면(로그인 사용자는 게임 화면에 처음 들어올 때)에서 아직 안 본 팝업 공지를 한 창에 최대 10개 모아 좌우로 넘겨 보여 주고(고정 공지 먼저, 그다음 최신순), 띄우는 순간 모두 "봤음"으로 기록해 다시 띄우지 않는다. 맨 위 [확인]이나 ESC로 닫는다.
- 게임 중 새 공지는 팝업 없이 [공지] 버튼에 빨간 점만 켠다. 목록에서 7일 이내 공지에 NEW를 붙인다.

### 4.17 게임 가이드
- 관리자가 카테고리와 글을 관리한다. 카테고리마다 FAQ형(아코디언) 또는 문서형을 고른다. 본문은 마크다운(허용 태그만), 이미지는 관리자가 올린 파일만, 한국어만.
- 초기 카테고리: 시작하기, 점수와 크기, 키워드, 아이콘과 칭호(이상 문서형), 자주 묻는 질문, 계정과 신고(이상 FAQ형).
- 가이드는 놀이 방법을 쉬운 말로 설명하고, 점수식·계수·기준값 같은 세부 수치는 쓰지 않는다. 아직 없는 기능은 "준비 중"으로 적는다.
- 제목·본문 검색, 글마다 고유 주소(`/guide/{카테고리}/{id}`), 게임 곳곳의 [?] 버튼에서 바로 연결.

### 4.18 나라와 언어

나라

| 코드 | 지역 | 기본 언어 | 오픈 | 데이터 소스 |
|---|---|---|---|---|
| KR | 한국 | 한국어 | 1단계(MVP) | 네이버 |
| GLOBAL | 영어권 통합 | 영어 | 2단계 | BigQuery 급상승 |
| JP | 일본 | 일본어 | 3단계 | BigQuery 급상승 |
| IN | 인도 | 힌디어 | 3단계 | BigQuery 급상승 |
| CN | 중국 | 중국어(간체) | 열지 않음 | 없음 |

- 한 사용자의 한 나라 기록을 플레이어라고 부른다(`players`). 닉네임, EXP·레벨, 칭호, 꾸미기, 트렌드 수치는 모두 플레이어에 속한다.
- 나라끼리는 완전히 별개다. 방·채팅·키워드·트렌드 값·댓글·랭킹과 사용자의 나라별 수치(유행도, 댓글 점수, `+` 횟수, 보유 키워드 수, 내 트렌드 키워드)와 닉네임, EXP·레벨, 아이콘 꾸미기, 칭호가 나뉜다. 합계 점수나 통합 랭킹은 없다.
- 계정 단위로 공유: 방문자 ID·구글 계정, UI 언어, 계정 금지, 이미지 업로드 정지, 탈퇴. 닉네임은 나라마다 따로 정하며, 새 나라에 처음 들어갈 때만 마지막 닉네임을 미리 채워 준다.
- 첫 접속 때 IP 국가와 브라우저 언어로 나라를 추천한다. 나라는 언제든 바꿀 수 있고, 떠난 나라의 내 트렌드 키워드는 남은 시간 동안 계속 기여한다. 한 계정은 한 번에 한 방에만 접속한다.
- 그 지역의 기본 언어를 지원하기 전에는 지역을 열지 않는다.
- 시간대: 날짜 경계와 04:00 배치는 나라 현지 시각(KR `Asia/Seoul`, GLOBAL `UTC`, JP `Asia/Tokyo`, IN `Asia/Kolkata`). 저장은 UTC, 화면은 선택한 나라 시간대.

언어
- 순서: 한국어(MVP) → 영어 → 일본어·중국어 간체·힌디어. 번체와 다른 인도 언어는 지원하지 않는다.
- 언어 결정: 사용자 선택 → 브라우저 언어 → 나라 기본 언어 → 영어(1단계는 한국어).
- 번역하는 것: UI 문구, 배지·칭호 이름, 약관. 번역하지 않는 것: 키워드, 댓글, 채팅, 닉네임, 공지. 사용자 글 자동 번역은 2차.
- 키워드 정규화(`keywords.normalized`, 같은 단어 판정용 비교 키): 공통 규칙은 NFKC → 소문자 → 모든 공백 제거 순서다(`K POP`, `ｋｐｏｐ`, `kpop`은 같은 키워드, `두바이 쫀득 쿠키`와 `두바이쫀득쿠키`도 같은 키워드). 화면에는 처음 입력한 표기(`text`)를 그대로 보여 준다. 하이픈 제거, 일본어 가나 규칙, 중국어 번체→간체(OpenCC), 힌디어 데바나가리와 로마자 처리 같은 언어별 규칙은 해당 나라를 열 때 추가한다. 한국어(KR)는 공통 규칙만 쓴다. 같은 함수를 검색, `+`, 외부 수집(10.2), 차단어 검사(4.6)에 쓴다.

### 4.19 트렌드 상자
아레나 곳곳에 잠깐 나타나는 상자를 열면, 지금 잘 나가는 키워드 하나를 나만 잠깐 볼 수 있다. 급상승 키워드를 모두에게 보여 주지 않는 원칙(3.3) 안에서, 직접 움직여 찾아간 사람에게만 주는 힌트다.

- 등장: 방마다 일정 간격(기본 5분)으로 무작위 위치에 생긴다. 한 상자는 일정 시간(기본 3분) 뒤 사라진다. 방에 동시에 최대 3개까지 있다. 벽 근처와 다른 상자 바로 옆에는 만들지 않는다.
- 키워드: 상자가 생길 때 서버가 그 나라에서 반영 소스가 외부인 🔥활성 키워드 중 트렌드 값이 기준 이상인 것 하나를 무작위로 정한다. 금지 키워드는 빼고, 최근 상자에 나온 키워드는 되도록 피한다. 같은 상자를 연 사람은 모두 같은 키워드를 본다. 후보가 없으면 상자를 만들지 않는다.
- 열기: 상자를 클릭한다. 내 아이콘이 상자 근처(기본 150px 이내)에 있어야 열린다. 멀면 "가까이 가야 열 수 있어요"를 보여 준다.
- 공개: 연 사람에게만 그 키워드의 카드(4.12, `+` 버튼 포함)를 일정 시간(기본 60초) 보여 준다. 시간이 지나면 카드에서 키워드 이름이 가려진다. 그동안 `+`하면 일반 `+`와 같다.
- 한 사람은 상자 하나를 한 번만 연다. 상자는 열어도 사라지지 않고 시간이 다 될 때까지 남아 있어서, 아직 열지 않은 사람은 각자 찾아가 열어야 같은 키워드를 볼 수 있다.
- 다른 사람에게 보이는 것은 상자의 위치와 남은 시간뿐이다. 누가 열었는지, 어떤 키워드인지는 보내지 않는다. 연 사람이 채팅으로 알려 주는 것은 막지 않는다.
- 상자 모양: 바닥 위에 반짝이는 선물 상자 아이콘, 사라지기 30초 전부터 깜빡임. 내가 이미 연 상자는 열린 모양으로 바뀐다. 미니맵에도 표시한다.
- 수치(간격, 유지 시간, 동시 개수, 최소 트렌드 값, 거리, 공개 시간)는 관리자 설정이다(13.3).

## 5. 범위

### 5.1 MVP와 2차

| MVP | 2차 |
|---|---|
| 방문자 ID, 닉네임 입장, 구글 로그인, 탈퇴 | 다른 소셜 로그인 |
| 아레나 이동·충돌·크기, 1000명 방 | 지역당 여러 방·서버 분산, 관전 모드 |
| 키워드 검색·`+`·점수, 24시간 삭제, 내 트렌드 키워드, 충돌로 키워드 잃기, 트렌드 상자 | 공유 카드 이미지 |
| 새 키워드, 키워드 생존주기 | 고급 담합 탐지 |
| 키워드 상세 카드(활동 그래프)·댓글·투표, 정보 팝업, 채팅, 랭킹 | 대댓글, 팔로우 |
| 성장 아이콘, 색·두께·픽셀 그림·업로드와 자동 검열 | 해금형 스킨·테두리 효과, 프리셋 이모지 선택, 차단 이미지 해시(pHash)로 재업로드 거부 |
| 칭호, 점수 추이, 공지사항, 게임 가이드 | 공지 예약 게시, 가이드 다국어 |
| 관리자 화면(금지, 가중치, 밸런스, 칭호, 공지, 가이드, 신고, 트렌드 키워드 목록) | 소스 장애 자동 차단, 나라별 밸런스 값·소스 가중치 |
| 한국어 UI(국제화 구조는 처음부터), KR 지역만 | 영어·GLOBAL, 일본어·중국어·힌디어, JP·IN |

### 5.2 보류 아이디어 (기록만, 구현하지 않음)

| 아이디어 | 내용 |
|---|---|
| 안전지대·점수 감소지대 | 아레나에 안전지대와 점수 감소지대를 만들어 집단을 이루거나 땅을 점령하게 한다 |
| 공격 스킬 | 특정 사용자의 내 트렌드 키워드 중 하나(무작위, 점수 최소 또는 최대)를 지운다 |
| 무적 스킬 | 일정 시간 충돌에서 튕겨 나가지 않는다 |
| 가속 스킬 | 일정 시간 이동 속도를 올린다 |
| 키워드 순위 공개와 순위 가산 | 사이트에 키워드 트렌드 순위(TOP 10)를 공개하고 상위 키워드의 `trend_value`를 올린다. 3.3의 비노출 원칙과 부딪히고, 순위가 굳어지는 순환이 생길 수 있다 |
| 외부 순위·세기를 `trend_value`에 반영 | 외부 소스의 순위·상대 비율을 가진 사람 수와 함께 계산한다. 외부 세기를 저장하는 컬럼이 필요하다 |

중복 조사
- 영문·한글 웹 검색에서 "키워드 검색 + 트렌드 점수 + 크기 + 밀어내기 충돌"을 결합한 게임은 찾지 못했다. 가까운 사례는 밀어내기 파티게임 Bubble Brawl(itch.io)과 트렌드 모음 앱 정도다. 출시 전에 Poki, CrazyGames, itch.io, 앱스토어를 직접 확인한다.

이름
- Trendist = trend + -ist(트렌드를 쫓는 사람). 검토했던 후보: 급상승.io, Trendsetter, Riser, Trender, Hipster, Trendier, 유행왕, 핫범퍼.io, 트렌드 스모. Trendsetter·Hipster 같은 어휘는 칭호로 쓴다.
- 같은 이름의 Trendist.AI(trendist.ai), 'The Trendist' 뉴스레터가 있어 혼동 가능성이 있다.
