## 관리 원칙

- 기능을 바꾸면 같은 작업에서 문서도 고친다. 문서는 "앞으로 만들 기획"과 "지금 프로젝트의 의도·동작"이 어긋나지 않게 유지한다.
- 고칠 때는 해당 절을 직접 고치고, 아래 변경 이력에 판 번호와 바뀐 내용을 한 줄씩 남긴다.
- 문서만 바뀌는 커밋은 `docs:`, 기능과 함께 바뀌면 그 기능 커밋에 같이 넣는다.

## 변경 이력

### 210판 (2026-11-09)
- **전체 화면 아이콘 깨짐 수정**: 글자 아이콘(⛶·🗗)은 폰마다 글꼴에 없어 □·×로 깨져서, 글꼴과 상관없이 그려지는 **SVG 아이콘**(`ui/FullscreenIcon.tsx`, 켜기는 모서리가 바깥으로·끄기는 안쪽으로, 글자색을 따름)으로 바꿨다. 위쪽 버튼과 ☰ 메뉴 항목 모두.
- **모바일 위쪽 전체 화면 버튼**: 🔍 왼쪽에 ⛶ 버튼을 두어 전체 화면을 바로 켜고 끈다(켜져 있으면 🗗와 초록 윤곽, 전체 화면을 지원하는 브라우저에서만 보인다). 끄면 다음부터 시작해도 자동으로 켜지 않는다.
- **모바일은 시작하면 전체 화면**: 브라우저는 누르는 순간(제스처)이 아니면 전체 화면을 허락하지 않아 페이지를 열자마자 바꿀 수는 없어서, **모바일(터치 기기)에서 [시작]을 누르는 순간** Fullscreen API로 주소창을 가린다. **컴퓨터는 켜지 않는다.** ☰ 메뉴의 ⛶로 직접 끄면 그 선택을 기억해(`trendist.autoFullscreen`) 다음부터 자동으로 켜지 않는다. 아이폰 사파리는 전체 화면 기능이 없어 해당 없음(홈 화면에 추가하면 주소창 없이 열린다).
- **조이스틱을 쥔 채 화면 버튼 누르기(전체 방식)**: 멀티터치에서는 click이 안 만들어진다. 버튼마다 따로 고치다 이모트 등을 놓쳐서, 게임 화면 전체에 `useMultiTouchClicks`(`ui/touchPress.ts`) 한 곳을 두었다 — **다른 손가락이 이미 닿아 있을 때** 누른 버튼은 누르는 즉시 click을 대신 일으키고(스킬·이모트와 이모트 창·접기 탭·채팅 접기·🔍·📦·☰ 메뉴와 그 항목 등 모든 버튼), 손가락이 하나뿐이면 평소 click을 그대로 쓰며 뒤따르는 진짜 click은 한 번 걸러 두 번 눌리지 않게 한다. 예전의 버튼별 처리(`SkillBar`·`BottomBar` 등)는 없앴다.
- **관리자 스킬 탭 개선**: 스킬마다 카드 한 장(아이콘·이름·종류 배지·기본 키·사용 스위치 / 쿨타임·해금 레벨 −＋ 입력 / 수정 시각·되돌리기·저장)으로 바꾸고 **해금 레벨 순서**로 보인다. 범위를 벗어난 입력은 그 자리에서 알리고 저장을 막으며, 바꾼 카드는 노랗게 표시하고 [모두 저장]/[모두 되돌리기]를 둔다. 해금 레벨 밑에 그 레벨의 필요 누적 EXP를 안내하고, 쿨타임에는 [없음(0)]·[기본값으로] 단축 버튼이 있다. 사용을 끌 때는 한 번 묻는다.
- **리더보드: 서버는 TOP 10, 화면 영역은 사람마다 조절, 영역 안에는 항상 내 순위**(4.14): 서버는 항상 TOP 10을 주고(관리자 설정 없음), 리더보드 아래 손잡이를 위아래로 끌어(키보드 ↑↓도 됨, 브라우저에 기억) 보이는 줄 수 N을 정한다. **최대**는 내가 10위 안이면 10줄, 11위 아래면 11줄(10위 + 내 순위 한 줄), **최소는 3줄**이다(내 순위 포함, 1등만 보이게는 못 한다 — 내가 1등이 아니어도 내 순위가 항상 보이게). N줄 안에는 항상 내 순위가 있다: 내가 N위 안이면 1~N위만(내 줄 강조, 아래에 또 안 보임), 그 밖이면 1~(N−1)위 + 맨 아래 내 순위 한 줄. 예) N=4에 내가 15위 → 1~3위 + 내 순위, N=3에 내가 3위 → 1~3위. 접속자가 적으면 있는 만큼만 보인다. 방에 없으면 내 순위 줄은 없다(`GET /api/rankings/me` 204).
- **브라우저 뒤로가기**: 시작 화면에서 [시작]으로 닉네임·게임 화면에 들어가면 히스토리를 한 칸 쌓아(`history.pushState`), 뒤로가기를 누르면 사이트를 떠나 이전 페이지(구글 로그인 화면 등)로 가지 않고 **시작 화면으로 돌아온다**. 닉네임→게임은 같은 칸을 쓰고, 로그아웃·탈퇴로 메인에 돌아오면 쌓은 칸을 걷어 낸다. 새로고침하면 항상 메인부터라 남은 기록은 지운다.
- **서버 응답 시간 표시**: 왼쪽 위 접속 인원·봇 옆에 서버와의 왕복 시간을 `● 42ms`로 보인다(ping 2초마다, 튀는 값에 안 깜빡이게 평균). 점 색은 네 단계: **초록 ≤80ms 쾌적 · 노랑 ≤150ms 보통 · 주황 ≤250ms 느림 · 빨강 251ms~ 불안정**(서버가 초당 20번=50ms마다 상태를 보내고 클라이언트가 내 움직임을 미리 그려 보정하는 구조라 80ms 안쪽은 차이가 없고 150ms까지는 보정으로 자연스러우며 250ms부터 스킬·충돌 반응이 눈에 띄게 늦다). 마우스를 올리면(길게 누르면) 설명이 보이고 연결이 끊기면 숨긴다.
- **관리자 [스킬] 탭**: 쿨타임은 `skills` 표로 옮기면서(V17) 관리자 설정 화면에서 빠져 있었다. 이제 관리자 화면에 **스킬 탭**을 두어 스킬마다 **쿨타임(0~3600초, 0이면 없음)·해금 레벨(1~100)·사용 여부**를 따로 고친다(`GET /api/admin/skills`, `PATCH /api/admin/skills/{code}`). 저장하면 DB에 바로 들어가고 서버 캐시를 비워 게임 방에는 1초 안에 반영된다. 키·아이콘·스킬 추가는 코드·DB 작업이다.
- **신고 대상 번호 정리**: 신고 `target_id`에는 **플레이어 신고면 플레이어 번호(players.id)**, **채팅 신고면 채팅 메시지 번호(chat_messages.id)**, 댓글·키워드는 각 번호를 넣는다. 플레이어 정보 창은 방에서 열었든 검색에서 열었든 카드의 `playerId`를 그대로 `PLAYER`로 보낸다(세션 번호 변환·`PLAYER_ID`는 없앴다).
- **모바일 세로 접기 탭·조이스틱 중 원 터치**: 명령 줄의 ▾ 접기 손잡이를 막대 윗면에 붙는 탭으로 바꿔(같은 바탕·테두리, 채팅은 그만큼 더 위로) 겹치지 않게 했다. 조이스틱을 쥔 채 다른 손가락으로 원을 누르면 카드와 표시는 바로 뜨고, 조이스틱을 쥐고 있는 동안은 조이스틱이 우선(따라가기 명령이 방향을 덮어쓰지 않음), 손을 떼면 그 원을 따라가기 시작한다. 터치는 탭일 수 있어 끌기가 시작될 때만 기존 따라가기를 멈춘다.
- **모바일 주소창 가리기**: 웹페이지가 주소창을 마음대로 숨길 수는 없어서 두 방법을 넣었다. ① **홈 화면에 추가**해서 열면 주소창 없이 전체 화면으로 실행된다(`manifest.webmanifest` display fullscreen + iOS 메타). ② ☰ 메뉴의 **⛶ 전체 화면**(Fullscreen API, 안드로이드 크롬 등에서만 보인다. 아이폰 사파리는 지원하지 않아 숨김).
- **모바일 세로 명령 줄 접기**: 명령 줄 위쪽 가운데의 ▾ 손잡이로 내 정보(초상화·경험치·유행도)를 접으면 스킬 5개와 이모트만 한 줄로 남고, ▴로 다시 편다(브라우저에 기억, 채팅 위치는 줄의 실제 높이를 따라 내려온다).
- **가이드 전수 최신화**(4.17): 실제 규칙과 어긋난 곳을 고쳤다 — `L`·`C` 단축키가 없어졌는데 남아 있던 리더보드 글, 봇을 이기면 "무작위 키워드"가 아니라 봇이 가진 키워드를 가져오는 것, 불꽃은 봇과의 싸움에서도 같은 힘, 입장 보호가 아니라 가운데 세이프존에서 시작, 점수가 같으면 아무도 잃지 않음. 빠졌던 내용을 더했다 — 콤보 5분 유지·접속하면 0부터·봇의 콤보·불꽃 물리, 알림 카드의 뺏음/뺏김/획득/잃음, 플레이어 탭·정보 카드(인기도·생성일·공유·신고 사유), 모바일 배치, EXP 얻는 법, 칭호 종류. 새 글 3개(죽음과 리스폰, 플레이어 검색과 인기도, 새로고침·연결 끊김)는 `GuideSeed.ADDED`로, 고친 글 12개는 `FIXES`(DB 본문이 예전 시드 그대로일 때만 교체, 영어 포함)로 이미 만든 DB에도 반영된다.
- **처치도 같은 결과 카드**: 키워드 없는 상대를 쓰러뜨린 알림(4.31)을 일반 알림 줄 대신 같은 카드 디자인으로 보인다(제목 "💀 쓰러뜨렸어요!", 둘째 줄 상대 이름).
- **불꽃으로 모두 날림·잃음도 같은 카드**: 불꽃으로 키워드를 모두 날리거나 잃은 경우는 빼앗기/빼앗김이 아니므로 구분 표시 없이 같은 결과 카드 디자인으로 보인다(제목 "🔥 불꽃으로 키워드를 모두 날렸어요!"/"🔥 불꽃에 키워드를 모두 잃었어요", 둘째 줄 "키워드 N개", 셋째 줄 상대 이름).
- **키워드 얻음·잃음은 한 가지 결과 카드로**: 구슬뿐 아니라 사람에게서 키워드를 빼앗을 때·빼앗길 때, 봇을 이겨 얻을 때, 부딪혀 잃을 때도 같은 카드(제목/키워드/상태·점수 줄)를 쓰고, 문구를 달리하는 대신 카드 위에 작은 표시만 붙인다: **획득**(구슬)·**잃음**(구슬)·**뺏음**(사람·봇을 이겨 얻음)·**뺏김**(사람·봇에게 져서 잃음). 상대 이름은 셋째 줄에 👤로 보인다. 불꽃으로 모두 날려 버린 경우와 상대만 키워드를 잃은 경우는 기존 알림 그대로.
- **신고는 같은 대상에게 하루에 한 번**(V25): `reports.report_date`를 두고 유니크 키를 `(유형, 대상, 신고한 사람, 날짜)`로 바꿨다. 날짜는 신고한 사람 나라 시간대의 그날이고 댓글·채팅·키워드·플레이어 모두 같다(옛 행의 고정 값 2000-01-01은 "오늘 이미 신고"로 세지 않는다). 플레이어 상세에서 하는 신고는 방에서 연 카드(`PLAYER`)든 검색에서 연 카드(`PLAYER_ID`)든 모두 그 **플레이어 신고**로 저장되어 같은 하루 한 번 규칙을 함께 쓴다. 같은 날 또 하면 409 `REPORT_DUPLICATE`("오늘은 이미 신고했어요").
- **신고 실패는 창 안에서**: 신고가 거절되면(이미 신고했어요 409 등) 창을 닫지 않고 신고 창 안에 빨간 문구로 알린다. 검색 상세에서는 문구가 다른 창 뒤에 숨어 보이지 않던 문제를 고쳤다.
- **구슬 결과 카드 세 번째 줄**: 키워드 상태·보유자 수(👥)·얻은 점수(`+내 유행도`) 또는 잃은 점수(`-내 유행도`)를 한 줄에 모두 보이고, 키워드 이름은 아무리 길어도 줄바꿈 없이 한 줄(넘치면 …, 전체 이름은 마우스를 올리면 보임). 카드는 내용만큼 늘어나되 최대 400px.
- **구슬 결과 카드 3줄**: 맨 위 "키워드를 얻었어요/잃었어요"(갱신 포함) → 다음 줄 키워드 이름 → 그 다음 줄 키워드 상태(얻은 경우는 상태 옆에 `+내 유행도`). 예전의 "점수·보유자 수" 줄과 잃을 때의 "-점수" 줄은 뺐다.
- **플레이어 상세에서 관리자 표시 제거**: 정보 카드 응답에서 `admin`을 없애 권한 정보가 화면·응답에 나오지 않는다. 구슬 확률 테스트의 기대 범위를 기본 60%에 맞게 고쳤다(가끔 실패하던 원인).
- **자기 자신 신고 불가**: 정보 카드 응답에 `me`를 두어 내 카드에는 신고 버튼과 인기도 +·− 버튼을 보이지 않는다(서버도 `REPORT_OWN`·`POPULARITY_SELF`로 막는다). 신고 사유에서 "고의 방해·괴롭힘"을 뺐다.
- **꾸미기 가로 모드(폰)**: 프로필 칸·미리 보기를 위에 쌓지 않고 **왼쪽 열**(36%)에 고정, 오른쪽 열 전체 높이를 꾸밈 항목(스크롤)과 저장 버튼에 주어 꾸밀 수 있는 영역을 크게 넓혔다. 창은 화면 가득(폭 100vw-20px, 높이 97dvh).
