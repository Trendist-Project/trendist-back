# Trendist 문서

> 유행을 아는 자, 커진다. 검색 트래픽으로 증명하는 "나의 유행 감각".

Trendist(트렌디스트)의 기획·설계 문서다. 이 백엔드 저장소의 `docs/`에서만 관리한다(프론트엔드 저장소에는 두지 않는다).

| 파일 | 내용 | 절 |
|---|---|---|
| [1-planning.md](1-planning.md) | 1부 기획: 개요, 플레이 흐름, 화면, 게임 규칙, 범위 | 1~6 |
| [2-tech.md](2-tech.md) | 2부 기술: 기술 스택, 프론트엔드, 백엔드, 트렌드 수집, 데이터 모델, 빌드·배포 | 7~12 |
| [3-operations.md](3-operations.md) | 3부 운영: 관리자 기능, 안전, 리스크, 열린 쟁점 | 13~16 |
| [4-schema.sql](4-schema.sql) | 4부 SQL: 스키마 DDL(MySQL 8) | 17 |

- 절 번호(1~17)는 네 파일에 걸쳐 이어진다. 코드 주석의 `(4.8)` 같은 번호가 이 절 번호다.
- 아직 정하지 못한 것은 16.1에, 직접 확인하지 못한 사실은 16.2에 모은다.

## 관리 원칙

- 기능을 바꾸면 같은 작업에서 문서도 고친다. 문서는 "앞으로 만들 기획"과 "지금 프로젝트의 의도·동작"이 어긋나지 않게 유지한다.
- 고칠 때는 해당 절을 직접 고치고, 아래 변경 이력에 판 번호와 바뀐 내용을 한 줄씩 남긴다.
- 문서만 바뀌는 커밋은 `docs:`, 기능과 함께 바뀌면 그 기능 커밋에 같이 넣는다.

- 모바일 상단 정리: 도구 버튼을 [🔍]과 [☰ 메뉴]만 남기고 나머지는 메뉴로, 접속 인원은 👥·🤖 아이콘으로 짧게(3.2)
- 로그아웃 강화: 도구 줄 [🚪 로그아웃], 로그아웃하면 갱신 토큰 폐기와 함께 그 전에 발급한 JWT도 바로 거절(`users.tokens_revoked_at`, JWT에 `iat` 추가). 갱신 토큰 쿠키 경로를 `/api/auth`에서 `/`로(개발자 도구에서 보이고 쿠키 지우기로 지워지게)(4.1, 9.3, 17)
- 메인 화면 [시작]과 구글 버튼을 같은 크기·모서리로 맞추고 "또는" 구분선을 둠(3.1)
- 게임 중 [🔑 로그인]·내 정보 [Google로 로그인]을 누르면 설명 창 없이 바로 구글 계정 선택(4.1)
- 구글 로그인을 계정 선택 페이지 방식으로 바꿈: `prompt=select_account`로 매번 계정을 고르고 다른 계정 추가 가능, `scope=openid`만, state·nonce로 위조·재사용 방지. 콘솔에 리디렉션 URI `/oauth/google-callback.html` 등록 필요(9.3)
- NPC 봇 추가: 사람 + 봇 10명이 되도록 채우고 사람이 오면 뺌, BOT 표시, 접속 인원·랭킹 제외. 봇은 키워드 없이 방 메모리 점수(0~1,000)만 갖고, 사람이 봇에게 지면 키워드를 잃고 봇이 지면 점수를 20~50 잃으며, 구슬은 33%로 점수 +20~50. 도망·추격·구슬·배회로 움직임. 설정값 `bot_players`·`bot_score_max`·`bot_step_min`·`bot_step_max`(4.3, 4.21, 13.3, 15)
- 봇을 사람과 같은 기준으로: EXP와 키워드 점수를 메모리에 갖고 유행도 = min(EXP, 100) + 합, 레벨은 레벨표. 유행도 상한은 방 1등의 1.5배(`bot_cap_ratio`, `bot_score_max`는 없앰). 닉네임은 모두 Bot, 원은 빨간색(4.21, 13.3)
- 누르고 있으면 그 자리로 계속 따라가게 함(마우스·손가락)(4.2)
- 튕김을 최대 속도에 비례하게: 밀려나는 거리 = 최대 속도 × 0.6초(`collision_knockback_distance`) × 세기, 0.5초 동안 처음에 빠르고 점점 느려짐. 밀려난 사람의 예측도 같이 밀려 화면이 순간 이동하지 않음(4.3, 13.3)
- 다른 플레이어 정보 보기를 PC 우클릭, 모바일 [🔍] 버튼 뒤 탭으로 바꿈(길게 누르기 없앰). 왼쪽 클릭·터치·드래그는 언제나 이동(4.2, 4.11)
- 충돌로 잃은 쪽은 3초 무적(`lose_protect_seconds` 10 → 3)이고 모두의 화면에 보호막과 카운트다운 표시. 잃은 사람에게는 키워드 이름 대신 몇 점짜리였는지만, 이긴 사람에게는 상대가 잃은 키워드와 점수를 보여 줌(봇은 점수만)(4.3, 13.3, 14)
- 봇 움직임을 사람처럼: 반응 속도 차이, 벽을 피하는 지그재그 도망, 앞질러 쫓기와 포기, 구슬 나눠 노리기, 곡선 배회와 잠깐 멈춤(4.21)
